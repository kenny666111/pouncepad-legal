# pouncepad-legal

Legal documentation for PouncePad, including Privacy Policy and Terms of Service.

## Files

- **privacy-policy.md** - Privacy Policy document
- **terms-of-service.md** - Terms of Service document
- **index.md** - Landing page with links to both documents
- **_config.yml** - Jekyll configuration for GitHub Pages

## GitHub Pages Setup

To enable GitHub Pages and make these documents accessible online:

1. Go to repository Settings
2. Navigate to Pages section (Settings → Pages)
3. Under "Source", select the **main** branch
4. Click Save

After enabling, the documents will be available at:
- `https://kenny666111.github.io/pouncepad-legal/` (index page)
- `https://kenny666111.github.io/pouncepad-legal/privacy-policy`
- `https://kenny666111.github.io/pouncepad-legal/terms-of-service`

## Note

These legal documents are provided as templates and should be reviewed by legal counsel before use in production.
